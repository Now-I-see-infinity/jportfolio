PORTFOLIO WEBSITE - QUICK START GUIDE
========================================

📁 FOLDER STRUCTURE:
-------------------
jportfolio/
├── index.html              (Home page)
├── about.html              (About & Experience)
├── projects.html           (Project showcase)
├── contact.html            (Contact & FAQ)
├── README.md               (Full documentation)
├── CONFIGURATION.md        (Setup guide)
├── css/
│   └── style.css          (All styles)
├── js/
│   └── script.js          (Interactivity)
└── php/
    └── send_email.php     (Email handler)

🚀 QUICK START:
---------------
1. Open: http://localhost/jportfolio
2. Customize personal info
3. Update projects & skills
4. Update social media links
5. Configure email in send_email.php

📝 KEY FILES TO EDIT:
---------------------
1. ALL HTML FILES:
   - Change "John Dev" to your name
   - Update social media links (href="#")

2. about.html:
   - Update about section
   - Update experience timeline
   - Update education/certifications

3. projects.html:
   - Add your projects
   - Update project links
   - Change categories as needed

4. contact.html:
   - Update contact info
   - Update FAQ questions/answers

5. php/send_email.php:
   - Change: $to = 'your-email@example.com'

6. css/style.css:
   - Change colors in :root section
   - Update fonts

🎨 COLOR THEME:
---------------
Edit css/style.css, update :root variables:
--primary-color: #667eea       (Main color)
--secondary-color: #764ba2     (Secondary)
--accent-color: #f5576c        (Highlights)

⚡ PERFORMANCE TIPS:
-------------------
1. Compress images before uploading
2. Minify CSS/JS for production
3. Enable GZIP compression (.htaccess included)
4. Use lazy loading for images
5. Cache static assets

🆘 TROUBLESHOOTING:
-------------------
Styles not loading?
  → Clear browser cache (Ctrl+Shift+Delete)
  → Check file paths

Links not working?
  → Update href attributes with actual URLs
  → Check URL spelling

Email not sending?
  → Check email config in send_email.php
  → Verify server mail() function works
  → Check firewall settings

Colors not showing correctly?
  → Check CSS color values
  → Clear browser cache
